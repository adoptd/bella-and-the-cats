# Bella & The Cats

Starter Next.js homepage for Bella & The Cats — premium apparel for pet people.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Deploy to Vercel

1. Create a GitHub repository named `bella-and-the-cats`.
2. Upload this project to the repository.
3. In Vercel choose **Add New → Project**, import the GitHub repository, and deploy.
4. Vercel will automatically redeploy when you push changes to GitHub.

The homepage currently uses the generated concept image as a visual placeholder. Replace `public/homepage-mockup.png` with final photography/product imagery when ready.
